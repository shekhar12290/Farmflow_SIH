# Architecture

The application follows a layered architecture:

- Frontend UI for farmers, buyers, and admins
- Backend API for product operations and demo logic
- AI layer for demand and pricing prediction
- Logistics layer for route optimization
- Data layer for simulated agricultural scenarios

## Flow

1. Farmer lists produce
2. AI predicts demand and supports pricing
3. Buyer searches and places orders
4. Matching engine identifies relevant farmers
5. Aggregation combines multiple supplies
6. Route optimizer plans the dispatch
7. Traceability and analytics capture outcomes
